## Einrichtung der gemeinsamen Datenbank (einmalig)

Damit alle Geräte dieselben Daten sehen, braucht die App ein kostenloses
Firebase-Projekt. Anleitung und Config-Vorlage: siehe Kommentar oben in
`firebase-config.js`. Ohne ausgefüllte Werte läuft die App weiter, zeigt
aber oben einen Hinweis, dass nicht gespeichert wird.
